# Integration run configurations

Keep each new run's resolved parameters here under its run ID. Record the method implementation, input manifest, seed, software environment and output run ID so a reader can reconstruct the invocation. This directory currently contains this guide. Historical fit parameters also appear in study protocols and generated run summaries.

The [path configuration example](../integration_paths.env.example) describes the input and workspace roots. Large outputs live under the [run registry](../../runs/README.md). The [transfer guide](../../../../../TRANSFER.md) shows how to restore inputs and launch a run from a fresh checkout.
