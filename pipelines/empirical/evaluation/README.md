# Empirical evaluation

This stage evaluates graphs and biological claims from the empirical pipeline.
It contains external evidence builders, peak-level validation, evidence tables,
and their interpretation. Simulation generation, cached simulation worlds, and
simulation scoring are in [`pipelines/simulation/`](../../simulation/README.md).

See [`results/`](results/) for current empirical findings and
[`outputs/`](outputs/) for curated, reproducible evidence tables and generated
evaluation artifacts.
