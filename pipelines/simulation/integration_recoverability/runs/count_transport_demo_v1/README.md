# Count-transport demonstration artifacts

See the [results and interpretation](../../COUNT_TRANSPORT_DEMONSTRATION.md).
The [plan](PLAN.md), [protocol](protocol.json), [fit seal](fit_seal.json) and
[evaluation seal](evaluation_seal.json) preserve the experiment's information
boundary. All 96 fits and all 32 assessment-evaluated selected-dimension starts
are retained. No new scientific worlds or count datasets were generated.

The first estimator did not recover useful cross-assay dependence on the two
cached simulation worlds. This is not a counterexample to the population E/E2
corollary, because the cached data do not satisfy its modeling assumptions.
