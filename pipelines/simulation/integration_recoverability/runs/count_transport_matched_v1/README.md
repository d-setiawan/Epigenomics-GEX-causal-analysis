# Exact-model E2 simulation artifacts

See the [results report](../../COUNT_TRANSPORT_MATCHED.md) for the primary
experiment and the separately labeled exploratory follow-up. This directory
retains all 144 capped/continued fits on nine exactly specified mechanisms,
their frozen selections, assessment results, figure and independent reviews.

The one-source model recovered the target in all three 12,000-cell conditions.
Higher-dimensional failures include demonstrably suboptimal stationary points;
they are not counterexamples to the population corollary. The source dimension
was supplied, and causal directions were not tested.
