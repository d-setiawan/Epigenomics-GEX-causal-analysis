# Unpaired multimodal benchmark

This track uses cached simulated worlds to study shared-state recovery across
unpaired modalities. `worlds/formal_worlds/` holds the cached input worlds and
`runs/formal_runs/` holds the formal run artifacts. They were moved without
rewriting their contents.

Discovery and truth-aware evaluation remain separate in the script and result
organization. The current benchmark and its limits are described in
[`results/ca_boss_v4_roadmap_status.md`](results/ca_boss_v4_roadmap_status.md)
and [`results/channel_aware_boss_v4_experiment_log.md`](results/channel_aware_boss_v4_experiment_log.md).
