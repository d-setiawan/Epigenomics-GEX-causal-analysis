# Project resources

Project-wide material that does not belong to one pipeline stage lives here:

- [`research/`](research/README.md) — mission, decisions, limitations, theory,
  planning, and literature.
- [`reports/`](reports/README.md) — project-wide reports and dated updates.
- [`outputs/`](outputs/README.md) — only deliverables shared across pipelines;
  stage-specific outputs stay beside their owner.
- [`archive/`](archive/README.md) — retained historical documents.

Pinned environment definitions remain in [`envs/`](../envs/README.md), since
they support both workflow families.
