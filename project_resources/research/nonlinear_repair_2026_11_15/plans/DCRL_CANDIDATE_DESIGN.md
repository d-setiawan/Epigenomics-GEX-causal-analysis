# DCRL within-assay candidate: pre-decision design

Status: scientific proposal only; no implementation or fitting. Author source commit `2f768e048cb49b2af674fe31f76e55374362c00e` under `../sources/dcrl_root/`, retrieval receipt therein. Theorem 1 is generic for K≥2 and targets latent distribution and measurement graph up to latent permutation, latent DAG up to Markov equivalence. K=1 below is an empirical baseline, not a theorem application. Neither predicts cross-assay joint truth.

Use already permitted within-assay training count vectors, keep their existing splits and assay selection, choose small K from {1,2} by a pre-specified training/calibration held-out count log score with training-only seeds. Fit each assay separately, with `known_Q=None`; no truth Q, latent state, paired cells, simulated data or test-driven selection. Freeze model-selection rules, source and input hashes before test evaluation. Compare count predictive log score against prespecified relevant count baselines and assess feature means, zeros, dispersion and sensitivity to depth/selection. Scores assess model prediction, not causal graph correctness; report both fit uncertainty and assay selection caveats.

The author `DAGEstimator` imports NumPy, SciPy, `factor_analyzer` and relative `data_generator`, `evaluation`, `initialization`, `latent_law`, `orientation`, `utils`, and config modules; exact complete dependency list and code-only import audit remain pending. Instantiate with `observed_X=X` shape N×J and `known_Q=None`, Poisson/PSAEM; direct `PSAEM` avoids `estimate`'s truth-graph evaluation unless the upstream observed-data wrapper provides equivalent semantics. Defaults in `ExperimentConfig.finalize`: `max_iter=20`, `tol=.05`, `C=1`, `epsilon=1e-50`, `kappa=1e-200`, penalty=N^(1/4), tau=2N^(-.275), gain=.5/(t+10), inner SLSQP cap=20. Fix all seed values and stopping criteria before execution; authors' single universal recommended seed was not found. Honor fail-stop diagnostics and report optimizer convergence rather than treating iteration cap as success.

The code's Poisson rate is additive nonnegative β0+Σβk z_k and bounded β0≤2, βk≤3 by default, with no cell-depth offset. For population held-out vector x, compute log Σ_z p̂(z)∏_j Pois(x_j;β̂0j+Σ_k β̂jk z_k) in log space over 2^K states, retaining zero-probability and zero-rate edge cases correctly. Cell-specific prediction conditional on a feature subset must use only the remaining observed features in the posterior and must never condition on a held-out target. Assess overdispersion and depth dependence; normalization or truncation alters the count model and requires explicit preplanning.

Compute the fitted support Q̂ using the actual code's final threshold rule; certificate algorithm checks existence of two disjoint K-row blocks with unit diagonals under row permutations, and ≥1 additional nonzero per latent column in remaining rows, and pairwise column noncontainment. Certificate failure rules out the theorem's displayed sufficient design for that fitted support; success only checks the estimated matrix, not true measurement structure, latent positivity, conditional independence, monotonicity, faithful latent DAG, correct likelihood or genericity. K=1 has no Theorem 1 certificate claim. Report latent state mass and graph equivalence as exploratory, with no ground-truth DAG claim.

Initializer uses rows k,K+k,2K+k and therefore needs J≥3K; it is row-order dependent and uses matrix inverses which may be singular. Coefficient bounds can saturate and initialization can contain problematic nonpositive rates; code inspection and controlled adaptation are needed before execution. The principal loop has approximate O(T C N K J) arithmetic plus J bounded optimizations per outer iteration, O(N(K+1)C) array storage, and potentially 2^K state operations in separate exhaustive objectives. No timed run was done, so no defensible wall-clock estimate for these assays is yet available; report actual elapsed time once an authorized fit is executed, with resource budget and fail-stop established in advance.

Source clarification: the first 3K row positions determine an initialization-time latent-column permutation; they are not supplied as a known Q or explicitly enforced as true anchors. Unknown-Q slope support is learned from data and hard-thresholded at `tau`, but optimizer and initialization are row-order sensitive. Use an explicitly frozen input order and report sensitivity if studied. `PSAEM(ite)` returns `(p_hat,B_hat,A_hat,t,loglik)`; `p_hat` is `SparseLatentLaw` from smoothed visited-state counts, B_hat stores intercept and slopes, and A_hat is final latent assignment. A nonvisited state can have zero fitted mass: do not conflate a fitted zero with failure or verification of the theorem's true positive-state requirement. Q_hat is `B_hat[:,1:] != 0` after the final support threshold. The Gibbs path uses global NumPy permutation/binomial randomness; set and record a distinct NumPy seed immediately before each fit, isolate processes, and record BLAS/thread settings. A rate-zero Poisson component is valid only for count zero; evaluate it with exact Poisson conventions and `logsumexp`. Do not silently clip invalid fitted rates. Some optimizer paths calculate log(rate) without a positive guard; a nonfinite objective, bound violation, or optimizer failure needs an explicit result and fail-stop. The inspected paper describes a stopping threshold but does not establish that its Poisson experiments used this current repository's 20-iteration defaults; distinguish code default from confirmed paper protocol.
