## Blocking: legitimate negative-infinite predictive score

A zero Poisson rate is allowed by the approved design. For B=0, p=(1,0,0,0), and test rows (1,0), (0,0), `exact_logprob` correctly returns (-∞,0). `evaluate.metrics` retains the -∞ mean as a float and `run.write` invokes `json.dump(...,allow_nan=False)`, which raises `ValueError: Out of range float values are not JSON compliant`. This deterministic fixture is reproduced in `fixtures.py` and would leave an incomplete evaluator directory, not a valid negative-infinite result. This is a legitimate zero-predictive-probability observation, not an invalid model or permission to drop the row.

Relatedly `worker.py` uses `not np.isfinite(cl).all()` as an `invalid_scoring` condition. A count vector with zero model probability in calibration is legitimate predictive failure and the fitted law remains a valid attained training solution; calibration is not the official penalized fit objective or start-selection criterion. Current behavior would exclude it from later test scoring. NaN, +∞, an invalid probability vector and negative/nonfinite rates remain errors. A revision should preserve the model, retain every row and exact zero rates, encode an aggregate -∞ as JSON null plus a clear `negative_infinity` status and `zero_probability_rows`, and distinguish finite values from invalid calculations in both calibration and evaluator. The existing source and protocol hashes should be preserved as a v1 snapshot; a revised test must exercise both the calibration and full output serialization paths, then source and protocol must be resealed before fitting. Do not apply clipping or retrospective selection.

## Checks performed

Read design, protocol, all five wrapper/test files, the relevant upstream `fit_observed`, `ExperimentConfig` and PSAEM implementation. Five sealed author tests pass in the isolated dependency environment. Independently checked all 4,096 six-row binary Q matrices against a separate exhaustive row-permutation certificate, plus an asymmetric 3-feature four-state Poisson mixture against SciPy and independently computed mean/variance/zero probabilities; all passed. Existing author tests additionally check the 1,024 five-row matrices, official sparse latent law state order, absent states and zero rates. These are deterministic fixtures and no scientific fits.

The wrapper calls the official observed-data API one separate process-level invocation per spectral seed, with unknown Q, standard backend and author column-sum orientation; official final score is observed likelihood minus TLP penalty, with highest score/first tie selected. The upstream source uses the same maximization rule, and separate calls prevent the legacy global RNG from colliding across parallel applications. The finalized Poisson settings, coefficient bounds, tolerance, initializers, gain, SLSQP cap, and 20-step maximum are consistent with the frozen plan and inspected author code. Per-start marker/checkpoint files and parent process 600-second kill preserve completed starts; an interrupted application is explicitly incomplete. Finite output with any optimizer failure or no tolerance stop is marked nonconverged. Fixed parameter bounds, no rescue and no depth offsets are model limitations; ordinary convergence diagnostics do not prove global optimization.

The fitted Q checker exactly implements the K=2 stated row-block, remaining coverage and noncontainment condition over the fitted support. Its result is a diagnostic of the estimated Q only: it neither establishes the unknown true Q nor genericity, true latent positivity, conditional independence, monotonic response, selection transport, causal Markov/faithfulness or theorem applicability. Exact numerical zero defines support; finite-precision threshold sensitivity remains a limitation.

Training reads only the nine specified public training matrices and permitted depth-derived diagnostics; seed-specific null controls permute within fit/calibration separately. The evaluator reads original public test arrays only after fit/source/approval validation and compares to frozen C01 Poisson fits, and does not read paired references or latent/causal labels. Prior C01 results informed C02, so heldout comparisons are sequential exploratory. Runtime package/version caveat: the protocol hashes the source tree and isolated extra dependency tree and records Python, NumPy and SciPy versions, but does not enumerate/hash every distribution in the base conda runtime (e.g. scikit-learn and BLAS shared libraries); thus treat its environment seal as partial, not a byte-level seal of the complete runtime. This does not itself demonstrate a mismatch, but a fuller environment receipt is recommended if complete dependency provenance is a requirement.

The likelihood fixture and other checks do not establish that all upstream execution paths work for all 36 inputs, that true Poisson rates are bounded by the author's constraints, or that stochastic SAEM reaches a global optimum. No fit was run in this review. Follow-up revision and independent re-review are required before approval.
