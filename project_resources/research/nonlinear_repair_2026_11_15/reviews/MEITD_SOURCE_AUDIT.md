# Zhang–Kileel MEITD source-only audit

Inspected pinned commit `3cad5393b0dbbd98e53a139bd6ad046d685fac2b` in `sources/zk_meitd_root`, with verified upstream blob and local hashes in `retrieval_manifest.json`; no code or data were run. The source-only snapshot contains README, `solver/MEITD.py`, `_N_coefs.py` and `__init__.py`.

`MEITD(d=4)` defaults to normalized order weights `(J−i)!/J!`. `solve_mean_weight(V, init_M, init_w, maxiter, ...)` expects J×N data, J×r initialized means, and r weights; maximum iterations has no default. Its defaults standardize each feature using training mean and sample SD, with no zero-variance check, but silently disable standardization for r<3. With `translate_init='data'` the starting means receive the same affine transform; it returns inverse-transformed means and weights. Caller must provide a quadratic-program solver callback, with interface `(unconstrained_mean, Hessian, lower_bound)` and simplex-sum constraint; `None` causes failure if weights are updated. The default lower bound is 0.1/r. No initialization strategy is supplied by the solver itself; starting values must be selected from training data using a sealed policy.

Repository defaults `warmup=0`, `AA_depth=0`, single-row updates and `Mtol=wtol=1e-4` therefore do not activate all of paper Algorithm 6's warmup, block and acceleration choices. `_update_M_block` always clips updated standardized means to the observed training data minimum/maximum, including after warmup; the paper describes the bound for warmup. Anderson extrapolation can subsequently move outside the cube, so validate the final inverse-transformed rates. The implementation has an unconditional global NumPy `seed(12345)` in `_step`; isolate the RNG or save and restore it and record this fact. Its weight stopping check uses absolute norm although docstring states relative; `ftol` contributes a diagnostic but `fconv` remains false in the inspected function. `scipy.linalg.solve(..., sym_pos=True)` requires compatibility with the supplied SciPy version or a separately reviewed API-preserving adaptation. A QP-failure fallback uses `goodidx = 1-badidx`, likely integer fancy indexing rather than Boolean complement; it must be independently checked and should not silently rescue failed QP runs.

For J=30 or 300 and r≤4 the population rank arithmetic holds at moments 2 and 3, with positive τ; the paper's comparative examples use orders 1–4 and explicitly include independent-Poisson mixtures. Computational complexity in the paper is per sweep O(JNr + Jr³ + T_QP(r)), with O(r(J+N)) auxiliary storage in its baseline analysis; actual implementation allocates additionally a `maxd×J×N` data-power array. These are not wall-clock estimates. Conditional independence, genericity and strictly positive weights are model assumptions; same selected class proportions across assays are a separate alignment assumption. ALS++ is a distinct heuristic, not automatically covered by baseline local-convergence theorem. Negative/nonfinite rates, zero-variance rows, singular solves, failed QP, lack of convergence and invalid weights must be reported as abstentions rather than silently floored. Any environment, solver callback, starts and evaluation changes require a complete reviewed plan before fitting.
