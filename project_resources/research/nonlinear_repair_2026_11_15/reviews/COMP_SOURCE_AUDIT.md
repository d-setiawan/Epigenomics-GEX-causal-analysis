# CoMP author source audit

Static source inspection only, 2026-11-15. `sources/comp_root/retrieval_manifest.json` pins commit `0da27c1795fefa6208ce2107f23fa534efdab833`; no data or code was executed. See [independent population applicability review](COMP_APPLICABILITY_REVIEW.md) for the distinct restricted product-Poisson/log-rate theorem.

`run.py` constructs `Encoder` and `GaussianDecoder` in `comp/nn/utils.py`. The encoder concatenates x with a one-hot condition, then applies a LeakyReLU network and returns a Normal posterior with learned location and fixed configured bandwidth. The decoder concatenates latent z and condition, uses a shared LeakyReLU MLP, and returns an independent-coordinate Normal with learned mean and one input-dependent standard deviation shared across output features (`0.01 + softplus`). There is no Poisson decoder in this entry point. The code conditions a common decoder on a label; it does not implement a separate nonsingular linear matrix for each condition, enforce latent dimension equal to feature dimension, or enforce independent asymmetric non-Gaussian latent factors. `COMP.forward_decoder(z, target_condition)` permits a model-based condition switch but does not identify individual target observations under the count model.

`comp/pl/comp.py` draws from q(z|x,c), scores Gaussian reconstruction and standard-Normal-prior KL, and subtracts the contrastive penalty from the ELBO. `make_subset_penalty_v2` evaluates pairwise log probabilities and normalizes by same-condition peer and other-condition sample counts: each batch needs at least two examples from every represented condition and at least one other-condition example or `log(0)` appears. The cost is pairwise in batch size. The practical learned VAE is therefore not automatically a faithful finite-sample estimator for the independent population theorem even though the conditional-population log-rate composition itself is valid under its separate assumptions.

The pinned requirements specify PyTorch 1.8.1 and PyTorch Lightning 1.2.5; README describes example training schedules of thousands of epochs with shared gene features and transformed data. A count-native, square log-linear, non-Gaussian-source estimator requires a separately specified implementation and finite-sample assessment; changing decoder family alone does not enforce the rest. Runtime, dependency compatibility and current-data applicability are not established. No fit is proposed or authorized here.
