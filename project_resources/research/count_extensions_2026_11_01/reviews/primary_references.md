# Primary sources used in the extension review

This is a targeted reference list, not an exhaustive systematic review. OpenAlex discovery and direct primary-source checking are recorded separately. The count-kernel and shrinkage formulas in the review are local derivations unless explicitly attributed.

- Podosinnikova, A., Bach, F., and Lacoste-Julien, S. (2015). *Rethinking LDA: Moment Matching for Discrete ICA*. NeurIPS 2015. [Official paper](https://proceedings.neurips.cc/paper_files/paper/2015/file/9be40cee5b0eee1462c82c6964087ff9-Paper.pdf). Model (4) and corrected-cumulant equations (10)–(13) motivate the within-assay Poisson source estimator. This paper is not a validation of the local NB/ZI correction or unpaired causal matching.
- Podosinnikova, A., Bach, F., and Lacoste-Julien, S. (2016). *Beyond CCA: Moment Matching for Multi-View Models*. PMLR 48:458–467. [Official paper and metadata](https://proceedings.mlr.press/v48/podosinnikova16.html). Generalized covariances motivate using several tilted second-order matrices instead of relying only on cubic orientation. Its multiview observation contract must not be silently transferred to unpaired source matching.
- Hafemeister, C., and Satija, R. (2019). *Normalization and variance stabilization of single-cell RNA-seq data using regularized negative binomial regression*. Genome Biology 20:296. [Full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC6927181/). DOI: 10.1186/s13059-019-1874-1
- Sarkar, A., and Stephens, M. (2021). *Separating measurement and expression models clarifies confusion in single-cell RNA sequencing analysis*. Nature Genetics 53:770–777. [Full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC8370014/). DOI: 10.1038/s41588-021-00873-4
- NIST Digital Library of Mathematical Functions, [equation 18.18.27](https://dlmf.nist.gov/18.18.E27). The Hille–Hardy identity supplies the Laguerre-polynomial kernel used in the review's conditional characteristic-function second-moment derivation. This is official mathematical reference documentation.
- SciPy, [confluent hypergeometric function documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.hyp1f1.html). API documentation was checked alongside the installed runtime's complex-argument calculations. The numerical conditioning proxy in the local implementation is a heuristic; it is not an accuracy guarantee supplied by SciPy.
