# Integration literature and causal recoverability

Start with the [synthesis](REVIEW.md). The review supports general limits on cross-assay causal recovery, while retaining published positive identification results under restrictive assumptions. It does not support universal impossibility.

- [Paper-by-paper matrix](PAPER_MATRIX.md): inputs, targets and implications for 64 selected papers.
- [Full evidence ledger](PAPER_EVIDENCE.json) and [spreadsheet-compatible table](PAPER_EVIDENCE.tsv): assumptions, inspected versions and evidence locators.
- [Search protocol](SEARCH_PROTOCOL.md), [search log](SEARCH_LOG.md), [discovery catalog](DISCOVERY_CATALOG.tsv), and [selection accounting](SCREENING_SUMMARY.json).
- [Citation checks](CITATION_CHECKS.md) and [machine-readable verification](citation_verification.json).
- [Review reconciliation and validation](REVIEW_RECONCILIATION.md): independent checks and final artifact hashes.

The existing [population proof](../theory/07_unpaired_integration_nonidentifiability.md) and [objective-specific companion](../theory/08_modern_integration_objectives.md) remain unchanged. This review identifies the model and observation conditions under which those proofs apply, and positive results outside their broad counterexample class.

Only public bibliographic metadata and papers were retrieved. No simulation worlds, biological datasets, integration fits or causal-test results were changed. Coverage and evidence limits are stated in the synthesis and search record; this is a scoping review, not an exhaustive systematic review.
