# Integration literature and causal recoverability

This November 1 scoping review compares the observations, targets and assumptions in 64 selected papers. Its broad-class counterexample covers direct cross-assay structure under disjoint sampling. Several published positive results obtain identification for specific targets by restricting the possible data-generating mechanisms. [Synthesis](REVIEW.md).
